Платформа менторства MentorMe

API-проект для поиска менторов и записи на обучающие курсы.

Все функции

Для всех пользователей (гостей)
- Просмотр списка всех курсов
- Просмотр детальной страницы курса

Для студентов (после регистрации)
- Запись на курс
- Отмена записи на курс
- Оставление отзывов (оценка + комментарий)
- Страница "Мои курсы" (список записанных курсов)

Для менторов (после регистрации с ролью "ментор")
- Панель "Управление курсами" (список своих курсов)
- Просмотр количества записанных студентов на каждый курс

Для администратора
- Полный доступ ко всем функциям (может расширяться)

Технические функции
- Регистрация с выбором роли (студент / ментор)
- Аутентификация (Laravel Breeze)
- API с документацией Postman
- База данных MySQL (таблицы: users, courses, categories, enrollments, reviews)

Запуск проекта

git clone https://github.com/kirillmokrushin/projextphpproject.git
cd projextphpproject/laravel
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve

После запуска открыть: http://127.0.0.1:8000
