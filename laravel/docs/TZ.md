Техническое задание: Платформа менторства MentorMe

Цель
Создать API-платформу для поиска менторов и записи на курсы.

Роли
- Гость (только просмотр)
- Студент (запись на курсы, отзывы, мои курсы)
- Ментор (управление своими курсами)
- Администратор (полный доступ)

Функционал

Все пользователи
- Просмотр списка курсов
- Просмотр деталей курса

Студент
- Регистрация / вход
- Запись на курс
- Отмена записи
- Отзывы (оценка + комментарий)
- Страница "Мои курсы"

Ментор
- Панель управления курсами
- Просмотр количества записанных студентов

Администратор
- Полный доступ (через БД)

API Endpoints
- POST /api/register
- POST /api/login
- POST /api/logout
- GET /api/me
- GET /api/courses
- POST /api/courses
- GET /api/courses/{id}
- PUT /api/courses/{id}
- DELETE /api/courses/{id}

Технологии
- Laravel 11
- PHP 8.5
- MySQL
- Bootstrap 5
- Laravel Breeze
- Laravel Sanctum
