# Техническое задание: Платформа менторства "MentorMe"

## 1. Цель проекта
Создать API для платформы, где эксперты (менторы) предлагают свои услуги в виде курсов, а ученики могут записываться, проходить обучение и оставлять отзывы.

## 2. Роли пользователей

| Роль | Описание |
|------|----------|
| **Гость** | Только просмотр менторов, курсов и отзывов |
| **Ученик** | Запись на курсы, просмотр своего прогресса, отзывы |
| **Ментор** | Создание и управление своими курсами, просмотр учеников |
| **Администратор** | Управление категориями, модерация курсов и пользователей |

## 3. Функциональные требования

### 3.1. Управление пользователями
- Регистрация / авторизация (Laravel Sanctum)
- Выбор роли при регистрации (ученик / ментор)
- Профиль: имя, email, аватар, биография

### 3.2. Управление категориями (только админ)
- CRUD категорий: "Программирование", "Дизайн", "Языки" и т.д.

### 3.3. Управление курсами (для ментора)
- Создание курса: название, описание, категория, цена, продолжительность
- Редактирование / удаление только своего курса
- Просмотр списка записавшихся учеников

### 3.4. Запись на курс (для ученика)
- Просмотр курсов с фильтрацией (по категории, цене, рейтингу ментора)
- Запись на курс / отмена записи
- Подтверждение прохождения курса ментором

### 3.5. Отзывы и рейтинг
- После завершения курса ученик оставляет отзыв (оценка 1-5, текст)
- Автоматический расчёт среднего рейтинга ментора

## 4. API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/courses` | Список курсов (пагинация, фильтры) |
| GET | `/api/courses/{id}` | Детали курса |
| POST | `/api/courses` | Создание курса |
| PUT | `/api/courses/{id}` | Обновление курса |
| DELETE | `/api/courses/{id}` | Удаление курса |
| POST | `/api/courses/{id}/enroll` | Запись на курс |
| DELETE | `/api/courses/{id}/leave` | Отмена записи |
| GET | `/api/categories` | Список категорий |
| GET | `/api/mentors` | Список менторов с рейтингом |
| POST | `/api/courses/{id}/complete` | Подтвердить прохождение |
| POST | `/api/courses/{id}/reviews` | Оставить отзыв |
